This file contains information on data made publicly available for
the paper "Stochastic low-frequency variability of 50 massive stars 
in the Cygnus OB associations and the Small Magellanic Cloud" by
M. G. Pedersen and L. Bildsten, accepted for publication by MNRAS on
14 April 2025.

-----------------------------
behind_the_figure.zip
-----------------------------
This directory contains all necessary files for reproducing figures
8-10 of the paper. Files are in Machine Readable Table format. 

-----------------------------
light_curves_and_PDS.zip
-----------------------------
This directory contains the residual light curves and calculated
power density spectra for all stars considered in the paper and for
all availble TESS sectors at the time of submission.

-----------------------------
tables.zip
-----------------------------
This directory contains the data available in Appendix tables A1 to
B2 in Machine Readable Table format.
